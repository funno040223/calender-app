# 運動見本の素材台帳

2026-11-21 制作。担当は Astra。すべて MovementGuide.tsx に座標と姿勢を定義した本アプリ用の独自作画です。外部の画像・動画・音声・フォントを使用していません。作画の第三者ライセンス表記は不要です。配布条件は本リポジトリに従います。

| 種目 | 作画・再生 | 動作の参考資料 |
| --- | --- | --- |
| 軽い足踏み | 横向きの交互の足上げ | 本アプリの運動仕様 |
| 壁腕立て | 壁と両手、肘の曲げ伸ばし | [NHS Strength exercises](https://www.nhs.uk/live-well/exercise/strength-exercises/) |
| リュックを引く | 安定した台と片手の荷物 | 本アプリの運動仕様 |
| 椅子から立つ | 椅子、座位・前傾・立位 | [NHS Strength exercises](https://www.nhs.uk/live-well/exercise/strength-exercises/) |
| ヒップブリッジ | 仰向けからの腰上げ | 本アプリの運動仕様 |
| ふくらはぎ伸ばし | 壁と後ろの足、左右の交代 | [NHS Flexibility exercises](https://www.nhs.uk/live-well/exercise/flexibility-exercises/) |

各見本には静止図と日本語の手順を付けています。「動きを見る」を選ぶと6秒の無音ループを再生します。端末で「動きを減らす」を選ぶと、姿勢を手動で送れます。
