# 眠りの記録（寝た・起きた時刻）を1か所にまとめる（第1段階）

2026-10-12。第1段階はデータの持ち方だけを変える。画面の動きと配置は変えない。

## 1. 困っていたこと

同じ意味の値が別々の場所にあり、読む場所ごとに直接見ていたので、値がずれていた。

| 意味 | 以前の置き場所 |
| --- | --- |
| 起きた時刻 | `wakeLogs[].wokeAt`（「起きた」・「いつ起きた？」）、`rhythmResets` の woke（立て直し「起きたところ」）、`wakeLogs[].routineStartedAt`（代わり） |
| 寝た時刻 | `bedLogs[日].at`（「寝る」）、`rhythmResets[].start`（立て直し） |
| 予定の起床 | `wakeLogs[].plannedWake`、`RhythmReset.plannedEnd`、今の `DayPlan.wake`（組み直すと変わる） |
| 予定の就寝 | `bedLogs[].plannedBed`、`dayLogs[前の日].bed`、予定の起床 − 睡眠時間 |

`night.ts` の `nightOf` が読み口のはずだったが、朝のカード・おやすみのカード・気づき・`wake.ts`・`bedtime.ts`・通知の送信（`/api/push/dispatch`）は直接読んでいた。

起きていた不具合：

- 立て直しの「起きたところ」で起きた時刻を入れても、朝のカードは「起きた」「いつ起きた？」のまま（`rhythmResets` にしか書かないため）
- そのとき予定の起床を残さないので、「予定どおり起きた」にならない
- 気づきの「起きて1時間」は `wokeAt` だけを見ていた

## 2. 新しい持ち方

眠りの記録 `sleepLogs: SleepLog[]` を1つだけ持つ（`model.ts`）。

| 項目 | 中身 |
| --- | --- |
| `id` | 夜の眠りは起きた日の日付。同じ日の昼寝などは `日付:寝た時刻` |
| `date` | 起きた日（まだ起きていなければ、起きる予定の日） |
| `nap` | 起きたあとの昼寝など（その日にもう活動開始（「起きた」「いつ起きた？」・立て直しの起床・朝ルーティンの最初のチェック。ヘルスケアの目覚めは数えない）があるあとに入れた立て直し）。夜の記録を置き換えず、その日の起床・就寝も動かさない（その間に枠を入れないだけ） |
| `bed` | 寝床に入った時刻 `{ at, source, recordedAt? }` |
| `up` | 起きて動き出した時刻 `{ at, source, recordedAt? }` |
| `until` | 「今から寝る」で入れた起きる予定（起きるまでは、ここまで眠るものとして組み直す） |
| `plannedBed` | 寝た時刻を記録したときの、予定の就寝 |
| `plannedWake` | 起きた時刻を記録したとき（「起きた」の前に朝ルーティンを始めたらそのとき。「今から寝る」は入れた起きる予定）の、予定の起床 |

`source` は `button`（「寝る」「起きた」）・`picked`（「いつ起きた？」）・`reset`（今から立て直す）。

そのまま残すもの：

| 項目 | 理由 |
| --- | --- |
| `healthSleep` | 測った値（ヘルスケア）。自分で入れた記録とは分ける |
| `rhythmResets` | 「疲れている」で休む時間だけにした（型は `TiredPause`） |
| `wakeLogs` | 朝だけの記録（朝ルーティンのチェック・`routineStartedAt`・疲れ・手で直した睡眠時間・`openedAt`）。`wokeAt`・`wokeRecordedAt`・`plannedWake` は外した |

## 3. 読み書きの口

読むのも書くのも `night.ts` だけを通す。

| 関数 | 役目 |
| --- | --- |
| `nightOf(data, 日)` / `allNights` | その夜の寝た・起きた・予定・ヘルスケア・睡眠時間（これまでどおり） |
| `sleepSessions(data)` | 組み直し用に、眠りを1回ずつ（立て直しを含むかの印つき） |
| `upRecorded` / `wakeStreak` | 起きたことを記録したか・続けた日数（`model.ts` から移した） |
| `plannedOf(result, 日)` | 記録するときに残す、今の計画での予定の起床・就寝 |
| `pressBed` / `undoBed` | 「寝る」・取り消す |
| `recordUp` / `undoUp` | 「起きた」「いつ起きた？」（直すとき・取り消すときも） |
| `notePlannedWake` / `dropPlannedWake` | 「起きた」の前に朝ルーティンを始めた・やめたとき |
| `recordReset` | 立て直しの「今から寝る」「起きたところ」 |

使う側：

| 場所 | 読み方 |
| --- | --- |
| 朝のカード（`MorningCard`、`isMorning`） | `nightOf` の `up`（立て直しの起床も「起きた」として出す）、`plannedOf` |
| おやすみのカード（`BedCard`） | `nightOf(翌日)` の `bed`・`plannedBed` |
| 立て直し（`RecoveryCard`・`recovery.ts`） | `recordReset`。予定の就寝・起床を `plannedOf` で残す |
| 組み直し（`state.ts`・`bedtime.ts`） | `sleepSessions` から `manualSleeps`（立て直し）と `bedtimeSleeps`（見積もり） |
| ご褒美・記録の画面・気づき（`stats.ts`・`insights.ts`） | `allNights` |
| 通知を止める朝（`wake.ts` の `awakeSince`、`/api/push/dispatch`） | `nightOf`。送信側も `fromStoredV2` で読み込む（古い形の行も移して読む） |

## 4. 移し方

`fromStoredV2` で、以前の項目が行に残っていれば眠りの記録に移す（`withLegacySleep`。MIGRATIONS に `2026-10-12-sleep-logs` を足した）。

| 以前 | 移す先 |
| --- | --- |
| `bedLogs[日]` | 翌日の夜の `bed`（button）と `plannedBed` |
| `wakeLogs[].wokeAt` / `wokeRecordedAt` | その日の夜の `up`（button）と `recordedAt` |
| `wakeLogs[].plannedWake` | その日の夜の `plannedWake` |
| `rhythmResets` の sleep・woke | 終わりの古い順に `recordReset` で重ねる（以前の「自分で入れた時刻を優先」と同じ結果） |

- 今の版は以前の項目を保存しないので、以前の項目があるのは古い版で保存した行だけ。印ではなく「残っていれば移す」にした（古い版の端末があとから保存しても失わない）。眠りの記録にもうある日はそちらを使う
- 2台での合わせ方（`merge.ts`）は夜ごと・項目ごと（`bed`・`up` などを別々に指紋にする）。片方だけ変えた項目はその変更、両方で変えた項目はサーバーのほう。古い記録は `pruneOldLogs` で400日、読み込みは500件まで
- 以前の版（開いたままの古い画面）が保存した行には `sleepLogs` がない。読み込むときは、この端末の眠りの記録のうち行にない夜を残し、サーバーにも送り直す（`keepLocalSleep`）。`public/sw.js` の VERSION も上げた
- 立て直しで入れた起床の朝は、計画の控え（`dayLogs[前の日].bed`）から予定の就寝と予定の起床（＋睡眠時間）を補う
- 移す前後で同じになることは `sleep-migration.test.ts` で確かめた（夜の記録・予定どおり起きた／寝た・ご褒美・今週のまとめ・連続日数）

## 7. 段階2：起きた時刻が遅れて分かった日の組み直し

前の計画は予定の起床から組んだもの。起きた時刻を遅れて記録した・前の時刻で入れたとき、前の計画がそのまま残り、朝ルーティン・朝食が消えたり、散歩・片付け・洗濯が重なったり2回入ったりしていた。

| 段 | すること | 場所 |
| --- | --- | --- |
| いつ | その日の活動開始（夜の記録の `up`。昼寝は数えない）が予定の起床から30分より大きくずれていて、まだその起床で組み直していないとき。組み直した起床は `anchoredWakes`（日付 → 起床。2台でも合わせる）に残し、同じ起床では二度しない | `state.ts` の `anchorOf` |
| 1 | 起床から今までに収まる、前の計画の自動の枠を外す（固定した枠・「今から何する？」で始めた枠・記録や確認の済んだ枠・今も続いている枠は残す）。外した作業の枠は進み具合を聞かず、外した記録しない習慣は始まった時刻も消す。この組み直しで1つ目（回す）を外した・寝ていたと分かった洗濯は、2つ目（干す）も外す | `anchorOf`・`replan` |
| 1 | 新しい朝ルーティンと重なる枠を外す | `planner.ts` |
| 2 | 過ぎていても、実際の起床から朝ルーティンを置き、朝の流れの記録する習慣（きっかけが朝ルーティンかそのあと：朝食・散歩）を過ぎた時間にも置く。食事の時間帯・3時間あける・昼食が入らなければ朝食を置かない（FR-H5）はこれまでどおり。記録しない習慣とタスクは過ぎた時間に置かない | `planner.ts`（`input.anchor`・`pastFree`） |
| 3 | 今からあとはこれまでどおり | |
| 4 | 過ぎた時間に置いた習慣はその日の分として残る（次の組み直しでは前の計画の枠として残し、同じ日にもう1つは置かない。「できなかった」にしたら過ぎた時間へは置き直さない） | |

「今から寝る」の起きる予定よりずっと遅く「起きた」を押した朝も、計画の起床を記録した起床にそろえる（`manualSleeps`）。予定から30分以内に記録した朝は、これまでと同じ並びになる（`late-wake.test.ts`）。大きくずれた日の判定・その日を軽くする・立て直しのカードをなくすのは段階3。

## 8. 段階3：立て直しのカードをふだんの画面に

（昼寝と朝帰りの判定は 9. でなくした。下の表のうち、その行は 9. の形が今のもの）

「今から立て直す」のカードをなくし、それぞれをふだん使う場所へ移した。データ（`sleepLogs`・休む時間 `rhythmResets`）はそのまま使う。

| 以前（立て直し） | 今 | 場所 |
| --- | --- | --- |
| 今から寝る（朝帰り・徹夜） | おやすみのカードの「寝る」。寝る準備の時刻からに加えて、前の朝に起きた記録があり、そのあと「寝る」も次の朝の「起きた」もないまま予定の就寝から3時間を過ぎたら、次の朝の予定の起床まで出す。このあいだ朝のカードは「起きた」「いつ起きた？」を出さない。起床は「寝る」と同じ見積もり（睡眠時間・固定の予定まで）。「寝る」を押したあとは、見積もった起床より前でも朝のカードの「起きた」を出す | `BedCard`（`bedNightOf`）・`recovery.ts` の `lateNightOf`・`MorningCard` |
| 今から寝る（昼寝） | 「今から何する？」の「寝る」。予定の就寝の3時間前からは、おやすみのカードの「寝る」と同じ（その夜の眠り・起床の見積もり）。それより前は昼寝：「起きた」を押すまで（それまでは60分として組み直す）。夜の記録・その日の起床は変えない。昼寝中の「起きた」は今日の画面のいちばん上に出し、朝の「起きた」「いつ起きた？」・朝ルーティンの最初のチェックでも終える。休んでいる間に寝たら、休む時間は寝た時刻で終える | `WorkNowCard`・`NapCard`・`sleepNow`・`closeNaps` |
| 起きたところ | 朝のカードの「いつ起きた？」 | `MorningCard` |
| 疲れている | 「今から何する？」の「休む」（終わりの時刻を選ぶ。初めは今夜の就寝まで）。休んでいる間は今日の流れに出し、「終える」で途中で終える（これからの自動の枠を置き直す） | `WorkNowCard`・`Timeline`・`endPause` |
| あとから直す | 寝た時刻はおやすみのカードで時刻を押して直す（起きた時刻と同じ） | `BedCard`・`correctBed` |
| 睡眠と重なる予定 | お知らせに出す | `Notices`・`sleepConflicts` |

ヘルスケアにその夜の睡眠が届いていれば、寝ていたものとして「寝る」は出さない。朝ルーティンのチェックを付ければ起きた記録になるので、早く起きた朝はそこから「起きた」に戻る。予定の起床を過ぎても寝ていない朝は、ふだんの朝のカードになる。朝の疲れ・睡眠不足でその日を軽くするのは、まだ決めていない。
