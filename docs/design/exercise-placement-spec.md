# 運動枠の適応配置仕様

2026-11-20。既存の予定配置へ運動候補を渡す実装前の判断仕様。これは予定整理のための商品判断案であり、体調の診断・運動の安全性判定・医療的な推奨を行わない。

## 目的と入力

一つの週次運動枠について、**通常・短縮・延期・見送り**を比較する。週2回の非連日などの目標は選べる目安で、未達を罰則・未完了タスク・翌週の追加義務にしない。運動習慣の設定、予定枠、実績は別IDで扱う。

入力は対象の習慣（通常・短縮の長さ、種目、頻度）、ローカル時刻と週、固定予定・睡眠・移動・休息、タスクの締切・残時間・優先度、本人が固定した運動枠、既存の完了・見送り・延期状態、前回のプラン、本人が任意で記録した当日の疲れとする。疲れは `低い／強い／不明`（回答なし・古い回答も不明）として扱い、未回答を「疲れなし」に置き換えない。既存の `DayEnergy` や生活予定の負荷は予定の見通しであり、本人の疲れ入力の代用にしない。毎日の追加質問を必須にしない。

## 候補生成と比較

各案を同じ入力・同じ既存スケジューラで個別に再計算し、候補外の枠は共通に保つ。候補時刻は設定された運動可能時間の空きから作り、枠の長さに移動・準備・運動後の休息が必要ならそれらも含める。タスク作業量は `remainingMinutes` があればそれを使い、なければ既存の見積もりを使う。比較値は案ごとに、締切までの不足分数、最長の連続作業時間、運動機会数・曜日、疲れの回答、動かす予定の件数・分数として保持する。負荷と締切を一つの点数に足さない。

| 案 | 候補の意味 |
|---|---|
| 通常 | 元の週次枠に通常版を置く。長さと休息を含めて実行可能なときだけ候補にする。 |
| 短縮 | 同じ枠に短縮版を置く。通常版では作業時間・余白を侵食し、短縮なら侵食を減らせる場合に比較する。自動枠は時間不足を理由に短縮候補へ変えられる。本人指定枠の自動短縮はせず、確認に戻す。 |
| 延期 | 同じ運動回を週内の別日に置く。元枠を空け、同じ回を別日に一つだけ保持する。翌週への繰越しはしない。本人指定枠からの延期は本人の確認後に確定する。 |
| 見送り | その週の回を置かない。作業・休息を確保でき、実行可能案がないとき、または本人が選んだときに提示する。未達分は翌週に加算しない。 |

## 厳守条件と優先順

比較は次の辞書式順序で行う。前段を満たさない案を後段の利点で選ばない。

1. **絶対制約**：完了済みの実績、固定予定、睡眠、明示された休息・移動時間、現在進行中の枠を保護する。重複する候補は除外する。実績は移動・短縮・再計算で変更しない。
2. **締切と本人の状態**：締切までに必要な作業時間を候補が新たに奪わない案を優先する。既存計画ですでに不足があるときは不足を隠さず、案ごとの不足分数を示す。強い疲れが本人から記録されている場合、通常を自動選択せず短縮・延期・見送りを提示する。不明時は疲れを推定せず、実行可能な通常と短縮等の候補を併記する。いずれも健康上の安全判定とは表示しない。
3. **週の運動機会**：上記を守る候補の中で、選択した頻度・非連日条件に沿った機会を残す。忙しい一日だけを理由に週全体から除かない。
週の機会が同じ場合は、タスクごとに確保すべき最小の連続作業区間と既存の余白を守れる案を優先する。短縮と別日の通常が並ぶときは、今日の短縮でその区間・余白を保てれば時刻を維持し、難しければ週内の通常へ移す。

4. **変更の少なさ**：同等なら既存枠の変更件数、変更分数が少ない案、次に元の時刻に近い案を選ぶ。完全同点は通常、短縮、延期、見送りの順とする。ただし強い疲れのときは通常を同点選択しない。

「固定予定・睡眠・休息」は常に守る制約。締切・疲れは候補の比較軸であり、締切を守るため固定枠を動かすことも、運動回数を満たすため締切作業や休息を侵食することもしない。全候補で締切不足が残る場合、アプリは自動で優先順位を決めず、不足時間と見送りを含む案を示して本人に判断を戻す。

## 揺れ、週境界、確定

- 再計算で選択済み・本人指定・開始済みの枠を変更しない。本人指定枠と固定予定が競合したら候補を確定せず、通常／短縮／延期／見送りを本人に選んでもらう。
- 自動枠の短縮・週内延期は候補計算後に適用し、ホームに理由・変更前後・「元に戻す」を出す。本人はいつでも見送りへ変えられる。本人指定枠を変更する場合に限り、延期先も本人が確定する。
- 同一入力の再計算は同一結果にする。候補案の順位が入れ替わる程度の小さな見積もり変化では、既存の未開始自動枠を保つ。再配置を許すのは固定予定の追加・変更、実際の起床/帰宅時刻の反映、タスク残量の更新など、実行可能性が変わる入力時。確定から外すときは理由と取り消しを記録する。
- 週は利用者のローカル時間の月曜〜日曜。運動回数は完了した実績だけを数え、予定・延期中・見送りは完了数に含めない。全身筋トレの非連日は、週をまたぐ前日・翌日の完了記録と確定枠も含めて判定する。日曜に実施したら翌月曜を通常の筋トレ日にしない。日付またぎの完了日は既存の起きている日の規則（`wakingDayStart`）で一度だけ記録し、その日の週に数える。
- 週をまたぐ延期候補は作らない。日曜時点の未実施分は閉じ、次週は新しい週次枠として組む。完了済み枠は次週に複製しない。

## 失敗時と既存プラン

候補ごとの再計算がエラー・上限時間超過・入力不整合になった場合は、その結果を保存・適用しない。直前の確定プランを維持し、「再調整できませんでした」と再試行手段を示す。空の候補結果や古い非同期結果で現行プランを上書きしない。再試行までの間も固定予定・実績は正本として維持する。

プランには世代/更新元を持たせ、候補の適用・取り消しは対象の自動枠だけに限定する。既存利用者は新プランを選んだ時点で初めて運動設定を切り替える。旧形式の習慣・枠・実績を読み込めない場合は黙って新規運動を追加せず、旧プランを保持して移行確認を出す。枠の再配置は実績や報酬を生成しない。完了操作は同一の運動回IDに対して一度だけ受け付け、通常/短縮のどちらで完了したかを保存する。

## 実装受け入れ例

| 入力例 | 期待する判断 |
|---|---|
| 月曜通常枠15分。空き180分、締切作業120分 | 通常を残し、作業120分と余白を確保。完了後は同じ回を再配置しない。 |
| 木曜の本人指定枠と固定予定が重なる。帰宅時刻・疲れは不明 | どの案も自動確定しない。通常・短縮・土曜延期・見送りと作業への影響を示し、本人が選ぶ。土曜への延期は本人確定まで保留。 |
| 自動枠は5分だけ空き、通常15分は夜の休息開始を侵食。締切作業の不足なし | 5分版を候補/適用し、「予定が詰まったため短縮」と元に戻す操作を示す。本人指定枠なら確認に戻す。疲れ不明を疲れなしとは扱わない。 |
| 通常・短縮とも火曜締切の必要作業を不足させ、週内に余裕ある日なし | 固定枠を動かさず、不足分数を示す。自動で運動を押し込まず、見送りを含む案を本人に提示。 |
| 水曜の全身運動を土曜へ延期して完了 | 木曜に同じ通常版を生成せず、完了実績・週回数は一件。次週に未実施分を足さない。 |
| 同じ候補計算がタイムアウト、または見積もりが数分だけ変化 | 旧確定プランを保持。結果なしで上書きしない。軽微な変化だけで短縮・延期が行き来しない。 |

## 週の具体例

同じ忙しい一週間で、上の判断がどう働くかを示す（時刻と作業量は説明用の架空データ）。

### 例の前提

- 対象週は月曜から日曜。通常の全身運動は15分、短縮版は5分。運動のない日は予定を増やさない。
- 固定予定、睡眠、食事、移動は動かさない。平日夜の休息時間は21:30以降。作業は分割できるが、まとまった作業時間も比較する。
- 火曜締切の資料は月曜までに計120分、金曜締切の提出物は週内に計180分必要。水曜までに120分を進め、木曜時点の残りは60分。必要量は見積もりで、実績・残量が分かれば更新する。
- 月曜の運動は自動配置。木曜19:30の運動は本人が選んだ枠。疲労の記録がない日は「疲れなし」とみなさず不明として扱う。

### 週の予定と候補比較

| 曜日 | 固定予定・締切 | 作業に使える時間 | 運動候補と判断 |
|---|---|---:|---|
| 月 | 9:00–18:00勤務。火曜締切資料の残り120分 | 18:30–21:30に180分 | 自動枠19:00。通常15分なら作業165分で不足なし。通常を選び、資料120分と余白45分を確保 |
| 火 | 9:00–18:00勤務。資料提出17:00 | 夜は休息優先 | 実施済みの月曜分を再配置しない。提出を記録 |
| 水 | 9:00–18:00勤務。金曜締切提出物の残り180分 | 18:30–21:30に180分 | 運動枠なし。120分作業し、木曜時点の残りを60分にする |
| 木 | 9:00–18:00勤務。19:30の固定予定が追加 | 180分から固定予定30分を引いた150分 | 本人指定の運動19:30が固定予定と重なる。通常・短縮・延期・見送りを提示し、本人に選択を戻す（下記） |
| 金 | 9:00–18:00勤務。提出物締切17:00 | 18:30–21:30に180分 | 木曜から延期しても自動で通常枠を置かない。締切後、本人が空き時間を確認して選ぶ |
| 土 | 10:00–12:00外出 | 13:00–17:00に240分 | 週内の別候補。本人が希望すれば運動を置ける。移動・休息を確保し、予定を勝手に埋めない |
| 日 | 固定予定なし | 任意 | 週の振り返り。未実施分を翌週の追加義務にしない |

#### 木曜の競合：4案を同じ基準で比較

木曜の19:30–19:45は本人が運動用に選んでいたが、後から19:30–20:00に固定の通院予定が入った。水曜までに提出物を120分進め、木曜時点の残りは60分。木曜夜は18:30–19:30と20:00–21:30が作業可能で、21:30以降は休息時間。固定予定と重なる本人指定枠を自動で移動・短縮・削除せず、選択肢と影響を示して確認する。

| 案 | 木曜の扱い | 締切作業への影響 | 週の運動機会 | 判定 |
|---|---|---|---|---|
| 通常 | 通院後の20:15–20:30に15分。移動・休息を含む空きが確認できた場合のみ | 20:30–21:30に残り60分を作業でき、締切不足なし | 月・木の非連日2回 | 条件付き候補。帰宅・移動の余裕と本人の疲れを確認してから提示 |
| 短縮 | 通院後の20:15–20:20に5分。休息開始を侵食しない場合のみ | 20:20–21:20に残り60分を作業でき、締切不足なし | 月・木の非連日2回（短縮完了として記録） | 通常が負担または時間超過なら候補。短縮で週の機会を残せることを表示 |
| 延期 | 土曜13:00以降の空きから本人が選ぶ。自動確定しない | 木曜は18:30–19:30と20:00–21:00に作業。残り60分を終えて30分の余白 | 土曜に実施すれば月・土で2回 | 本人の選択待ち。木曜は未実施のまま保持し、土曜に重複枠を自動生成しない |
| 見送り | 今週は木曜分を実施しない | 木曜は18:30–19:30と20:00–21:00に作業。残り60分を終えて30分の余白 | 月曜の1回 | 他の候補が休息・固定予定・締切作業を損なう、または本人が見送りを選ぶ場合。翌週へ積み増さない |

この例では、通院後の帰宅時刻と疲れが分からないため、通常・短縮を自動確定しない。アプリは候補の所要時間と条件を示し、本人が「通常」「5分だけ」「土曜へ延期」「見送る」を選ぶ。土曜の延期先も、本人の確認後に確定する。どの選択でも本人指定枠の変更理由・元の時刻・取り消し手段を残す。

### 同じ週で条件を変えた例

以下は上の週の前提だけを変えた反実仮想。曜日・締切は同じにして、候補の判断が変わることを示す。

#### 自動枠を週内へ延期

月曜の外出が延び、夕食後の空きは19:30–21:30の120分。翌日の締切までに使える作業時間はこの120分だけで、残作業も120分。通常15分なら15分不足、短縮版でも5分不足、延期なら不足0分になる。この例では火・水・金・日は固定予定と休息で埋まり、木曜は別の本人指定枠がある。土曜13:00–13:15なら木曜の筋トレと非連日で通常版を確保できる。

**結果**　月曜の自動枠を土曜13:00へ移す。今週の予定は木・土の2回。ホームには変更先と取り消しを表示し、本人に再選択を求めない。実施回数は完了するまで増えない。

#### 週内すべてが逼迫し見送り

同じ週で、月曜から金曜は固定予定の延長により休息開始前の空きがなく、火曜・金曜締切の作業にも遅れが出ている。土曜は10:00–12:00の外出後、13:00–17:00に締切遅延分の作業が必要。日曜も家族との固定予定が入り、移動・休息を含めて運動を置ける時間がない。次週も既存の予定があり、未実施分を追加すると過密になる。

**結論：** 今週分は見送りとして確定可能にする。固定予定・必要作業・休息のどれかを崩して運動を自動配置しない。締切の不足分と見送りを別々に示し、運動を未完了タスクにせず、翌週へ積み増さない。

#### 5分だけ可能なら自動短縮

同じ週の月曜19:00の自動枠について、外出延長後の帰宅は20:00。20:05–21:25は夕食・身支度の固定ルーティン、21:30から休息なので、20:00–20:05だけが空く。通常15分を置くと固定ルーティンを10分侵食する。火曜締切資料はすでに提出済みで、月曜夜に追加作業はない。疲労記録はなく不明。

**結論：** 自動枠なので、予定上5分だけ実行可能なら5分版へ短縮して提案できる。画面上で「予定が詰まったため5分版」と変更理由を示し、元に戻す操作を置く。疲れが不明のまま通常版を強行せず、本人は見送りにも変更できる。短縮を完了した場合だけ1回の実績として記録する。

### この週での受け入れ条件

- 上記の週を入力すると、火曜・金曜の固定締切を守る候補を選べる。詳細画面では各案の作業時間と締切不足分数を確認でき、通常画面には比較数値を並べず、選んだ案と短い理由を示す。
- 月曜に通常版を完了した後、火曜や木曜への同じ枠の自動複製がなく、実績は1回だけ数える。
- 木曜の本人指定枠と追加固定予定が衝突した場合、本人指定枠を無断で動かさず、通常・短縮・延期・見送りを選べる。各案の作業時間への影響は詳細で確認できる。
- 通院後の帰宅時刻または疲労が不明なら、条件を確定扱いせず、確認なしで運動を配置しない。
- 木曜から土曜への延期は本人の確認後に確定する。延期中の同一運動を金曜・土曜に重複配置せず、土曜の固定予定や休息を侵食しない。
- すべての案で締切不足が生じる入力では、詳細で不足分数を確認でき、通常画面では不足があることを明示する。固定予定を動かさず、見送りや本人判断に進める。
- 自動枠で残り5分のみ実行可能なら短縮版を提案し、その理由と元に戻す操作を示す。本人指定枠には同じ自動短縮を適用せず、本人確認に戻す。
- 自動枠が当日実行できず、週内に締切・固定予定・休息を守れる候補日がある場合は自動枠を延期し、取り消せる。全日が逼迫して実行可能な候補がない場合は見送りを選べ、翌週に積み増さない。
- 見送りはその週の運動回数にだけ反映し、タスク残件・罰則・翌週の追加義務を生まない。
- 選択の取り消しで元の予定・時刻に戻せる。完了後の再表示や同期でも実績・報酬の二重計上がない。
